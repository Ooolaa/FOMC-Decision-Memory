# FOMC 情境投票預測實驗室（新增離線展示）

直接以瀏覽器開啟 `FOMC_Vote_Scenario_Lab.html` 即可，不需要 Python、網路或 API 金鑰。

功能：

- 輸入七項與原 R5 pooled ordered-logit 相同的總體／市場特徵。
- 從封存的委員輪廓中挑選特定委員；也可改寫其歷史投票數與異議數作情境測試。
- 輸出政策情境的三類機率（降息／維持／升息）、該委員對主要政策提案的 FOR／AGAINST 預測、異議風險和可重算理由。

## 模型邊界

這不是對個別委員重新訓練出的行為模型。R5 的封存資料明確說明其宏觀係數是跨會議共用（pooled），沒有估計個人係數；個別投票基準則是「先前異議率達 10% 時標為 AGAINST」。因此新展示嚴格把：

1. 經濟情境對政策方向的推論，和
2. 委員歷史異議率所產生的可稽核投票風險

分開顯示，並揭露限制，避免把推定立場說成事實。

## 不變更原 R5 交付包

此檔案位於交付包根目錄，未修改 `02_Application/` 的任何 manifest 管理檔案。原 R5 缺少的 runtime SQLite 資料庫仍需另行取得；這個新增展示僅使用封存 JSON 中的係數與輪廓數值，故可離線運作。
